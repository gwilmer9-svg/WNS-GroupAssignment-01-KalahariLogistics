# WNS-GroupAssignment-KalahariLogistics

## Project Description
Wireless/WAN design for Kalahari Logistics Ltd, connecting
Windhoek HQ to Walvis Bay, South Africa, and an EU data centre.

## Network Design Summary
- Windhoek HQ: wired LAN plus wireless AP
- Walvis Bay: MPLS leased line
- South Africa: VPN over the internet
- EU data centre: VSAT satellite
